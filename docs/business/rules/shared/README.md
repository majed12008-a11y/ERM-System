# Shared Rule Assets

## Purpose
Store shared guidance and cross-category rule assets that support future rule catalogs.

## Scope
Cross-category indexes, shared review notes, shared taxonomy support, and repository-level reusable assets.

## What Belongs Here
Shared rule repository assets that are not individual business rules.

## What Does NOT Belong Here
Actual business rule records that belong in a classification folder.

## Naming Convention
Use descriptive lowercase kebab-case file names for shared assets.

## Review Responsibility
Business Rules Architecture owns review of shared repository assets.
