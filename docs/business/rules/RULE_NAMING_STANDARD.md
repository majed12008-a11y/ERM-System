# Rule Naming Standard

## Purpose

This document defines naming expectations for future business rule files and rule names.

## Rule Names

Rule names SHALL be concise business names.

Rule names SHALL describe the business expectation without implementation language.

## File Names

Rule file names SHALL start with the rule ID.

Rule file names SHOULD use lowercase kebab-case after the rule ID.

Example: `BR-000001-short-rule-name.md`
