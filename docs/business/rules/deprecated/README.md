# Deprecated Rules

## Purpose
Store future deprecated rule records that remain visible but should not govern new work.

## Scope
Deprecated rules awaiting supersession, archive, or historical retention decision.

## What Belongs Here
Deprecated business rule records retaining their original rule identifiers.

## What Does NOT Belong Here
Active approved rules, draft rules, or archived historical-only records.

## Naming Convention
Use the original rule file name and identifier.

## Review Responsibility
Business Rules Architecture coordinates deprecation review with the rule owner and approval authority.
