# Configuration Rules

## Purpose
Store future rules that govern business-level settings, controlled options, institutional choices, and responsibility parameters.

## Scope
Configuration rules for institution-level governance settings, responsibility options, review options, and controlled business parameters.

## What Belongs Here
Approved or candidate configuration rule files using the assigned configuration number range.

## What Does NOT Belong Here
Technical configuration, environment settings, or implementation-specific behavior.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with product governance and affected business owners.
