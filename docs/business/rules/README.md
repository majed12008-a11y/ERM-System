# Business Rules Repository

## Purpose

This repository stores future ERM-System business rule catalogs and supporting rule governance assets.

## Scope

This repository contains rule category folders, lifecycle folders, indexes, standards, and templates.

## What Belongs Here

- Approved business rule catalog files.
- Draft business rule catalog files.
- Deprecated and archived business rule records.
- Business rule indexes.
- Business rule repository guidance.

## What Does Not Belong Here

- Software implementation.
- Database design.
- API definitions.
- User interface specifications.
- Unapproved rule content outside the draft area.

## Naming Convention

Future rule files SHALL use the rule identifier and concise kebab-case title, for example `BR-000001-short-rule-name.md`.

## Review Responsibility

Business Rules Architecture owns this repository structure. Business owners own individual rule meaning.
