# Reference Rules

## Purpose
Store future rules that govern controlled terms, classifications, reference lists, templates, and guidance references.

## Scope
Reference rules for terminology, approved values, document references, guidance, and reusable business definitions.

## What Belongs Here
Approved or candidate reference rule files using the assigned reference number range.

## What Does NOT Belong Here
General glossary content or uncontrolled notes that are not business rules.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with Domain Architecture and reference stewards.
