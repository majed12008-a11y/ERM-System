# Integration Rules

## Purpose
Store future rules that govern business information exchange, cross-institution coordination, external stakeholder expectations, and authorized sharing.

## Scope
Integration rules for institutional coordination, national oversight exchange, regulatory coordination, and external stakeholder information needs.

## What Belongs Here
Approved or candidate integration rule files using the assigned integration number range.

## What Does NOT Belong Here
Technical integration designs, APIs, protocols, or implementation details.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with coordination owners and governance authorities.
