# Security Rules

## Purpose
Store future rules that govern confidentiality, authorized business purpose, access responsibility, and sensitive information handling.

## Scope
Security rules for research ethics governance information, stakeholder responsibility, confidentiality, and business access constraints.

## What Belongs Here
Approved or candidate security rule files using the assigned security number range.

## What Does NOT Belong Here
Technical security implementation, software configuration, or non-security business rules.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with Security Governance.
