# Notification Rules

## Purpose
Store future rules that govern business notices, reminders, requests, acknowledgements, and communications.

## Scope
Notification rules for application status, review activity, conditions, decisions, overdue actions, and governance communications.

## What Belongs Here
Approved or candidate notification rule files using the assigned notification number range.

## What Does NOT Belong Here
Workflow, scheduling, or communication record rules whose primary purpose is not notification triggering.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with process owners and Institution Administration.
