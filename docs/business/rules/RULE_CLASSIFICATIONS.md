# Rule Classifications

## Purpose

This document lists the approved business rule classifications for ERM-System.

## Classifications

- Eligibility
- Validation
- Workflow
- Decision
- Approval
- Committee
- Compliance
- Regulatory
- Security
- Notification
- Scheduling
- Reporting
- Retention
- Audit
- Reference
- Calculation
- Configuration
- Integration
- System Constraints
- National Policy

Each future rule SHALL have one primary classification.
