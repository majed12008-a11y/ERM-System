# Archived Rules

## Purpose
Store future archived rule records retained for historical reference.

## Scope
Archived rules that no longer govern active behavior but must remain traceable.

## What Belongs Here
Archived business rule records retaining their original rule identifiers.

## What Does NOT Belong Here
Active, draft, approved, or deprecated rules that have not been archived.

## Naming Convention
Use the original rule file name and identifier.

## Review Responsibility
Business Rules Architecture coordinates archive review with the rule owner.
