# Audit Rules

## Purpose
Store future rules that govern audit evidence, audit readiness, audit access, audit scope, and audit trail expectations.

## Scope
Audit rules for governance records, approvals, decisions, evidence, communication records, and oversight reviews.

## What Belongs Here
Approved or candidate audit rule files using the assigned audit number range.

## What Does NOT Belong Here
Compliance, retention, or security rules whose primary purpose is not audit governance.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with audit and oversight authorities.
