# Retention Rules

## Purpose
Store future rules that govern retention, archival expectations, disposal eligibility, and historical record availability.

## Scope
Retention rules for applications, decisions, evidence, approvals, certificates, communications, audit evidence, and governance records.

## What Belongs Here
Approved or candidate retention rule files using the assigned retention number range.

## What Does NOT Belong Here
Audit, security, or archive-only files whose primary purpose is not retention governance.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with records, audit, and governance authorities.
