# Rule Status

## Purpose

This document defines allowed status values for future business rules.

## Status Values

| Status | Meaning |
| --- | --- |
| Identified | Candidate rule recognized but not fully specified. |
| Draft | Rule documented but not ready for approval. |
| Review | Rule ready for stakeholder review. |
| Approved | Rule accepted by the proper business authority. |
| Implemented | Rule realized in the approved operating environment. |
| Verified | Rule has verification evidence. |
| Deprecated | Rule remains visible but should not govern new work. |
| Superseded | Rule replaced by another rule. |
| Archived | Rule retained for historical reference only. |
