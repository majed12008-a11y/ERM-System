# Workflow Rules

## Purpose
Store future rules that govern business progression, routing, sequencing, lifecycle behavior, and state movement.

## Scope
Workflow rules for application lifecycle, review lifecycle, conditions, approvals, amendments, closure, archiving, and audit handoffs.

## What Belongs Here
Approved or candidate workflow rule files using the assigned workflow number range.

## What Does NOT Belong Here
Decision, approval, notification, or scheduling rules whose primary purpose is not workflow control.

## Naming Convention
Use `BR-NNNNNN-short-rule-name.md`.

## Review Responsibility
Business Rules Architecture coordinates review with Enterprise Business Process Architecture.
